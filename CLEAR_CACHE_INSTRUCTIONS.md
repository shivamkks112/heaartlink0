# Android App में Navigation Fix देखने के लिए

## Method 1: App को Force Stop करें
1. **Settings** खोलें
2. **Apps** → **HeartLink** 
3. **Force Stop** दबाएं
4. **Clear Cache** दबाएं (NOT Clear Data)
5. App फिर से खोलें

## Method 2: App Reinstall करें (सबसे अच्छा तरीका)
1. App को **Uninstall** करें
2. नया APK build करें या existing APK reinstall करें
3. App खोलें और login करें

## Method 3: Browser में Test करें (सबसे आसान)
1. Mobile browser खोलें (Chrome/Firefox)
2. https://heartlink-dating-2.preview.emergentagent.com खोलें
3. Browser cache clear करें:
   - Chrome: ⋮ → History → Clear browsing data
   - Firefox: ⋮ → Settings → Clear private data
4. Page reload करें (F5 या Pull down)
5. Login करें

अब navigation bar **नीचे** दिखेगा!

## अगर अभी भी नहीं दिख रहा:
- Browser को **Hard Refresh** करें: Ctrl+Shift+R (Desktop) या Force Refresh
- **Incognito/Private Mode** में खोलें
- Different browser try करें
