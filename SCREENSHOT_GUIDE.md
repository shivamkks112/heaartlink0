## How to Take Screenshots:

### Method 1: From Your Phone (Best Quality)

**Steps:**
1. Install HeartLink APK on your phone
2. Login with test account (priya.sharma@test.com / test123)
3. Navigate to each page
4. Take screenshot (Power + Volume Down)
5. Screenshots saved in Gallery/Photos

**Important:**
- Use clean demo accounts (no test emails visible)
- Hide status bar (Settings → Display → Hide system bars)
- Portrait mode only
- Good lighting, clear display
- No personal data visible

### Method 2: Using Android Studio Emulator

**Steps:**
1. Open Android Studio
2. Run app on emulator (Pixel 5 recommended)
3. Navigate to each page
4. Camera icon in emulator toolbar
5. Screenshots saved in specified folder

**Settings:**
```
Device: Pixel 5
Resolution: 1080 x 2340
Android: 13.0 (API 33)
```

### Method 3: Using ADB (Advanced)

```bash
# Connect phone via USB
adb devices

# Take screenshot
adb shell screencap -p /sdcard/screenshot1.png

# Pull to computer
adb pull /sdcard/screenshot1.png
```

## Screenshot Best Practices:

### ✅ DO:
- Use real device for authentic feel
- Show actual app functionality
- Use attractive demo profiles
- Keep UI clean and uncluttered
- Show variety of features
- Use consistent lighting
- Portrait orientation only

### ❌ DON'T:
- Show personal information
- Use test emails (test@test.com)
- Include debug data
- Show errors or bugs
- Use landscape orientation
- Over-edit or filter
- Show empty states
