# 🏪 Play Store Preparation Checklist - HeartLink

## Phase 1: Google Play Console Setup

### Step 1: Create Developer Account

**URL:** https://play.google.com/console/signup

**Requirements:**
- Google account (Gmail)
- $25 USD one-time registration fee
- Credit/Debit card
- Valid ID (for verification)

**Process:**
1. Visit Google Play Console
2. Click "Sign up"
3. Fill developer information:
   - Name: [Your Name]
   - Developer name: HeartLink Technologies (or your company)
   - Email: [Your professional email]
   - Website: https://heartlink.co.in
4. Pay $25 fee
5. Verify email
6. Wait for approval (usually instant)

**Important:**
- Use professional email
- Developer name is public (choose wisely)
- Can't change later easily

## Phase 8: Submission Process

### Step-by-Step Submission

1. **Create App in Play Console**
   - Dashboard → All apps → Create app
   - App name: HeartLink
   - Default language: English (US)
   - App/Game: App
   - Free/Paid: Free

2. **Setup Store Listing**
   - Upload all assets
   - Fill descriptions
   - Add contact details
   - Set category

3. **Setup Content Rating**
   - Complete questionnaire
   - Receive rating certificate

4. **Setup App Access**
   - All features: Available to all users
   - Or require login: Yes (explain)

5. **Setup Privacy Policy**
   - Add privacy policy URL

6. **Setup App Content**
   - Ads: Yes/No
   - Target audience: 18+
   - News app: No

7. **Create Release**
   - Production → Create release
   - Upload AAB/APK
   - Add release notes
   - Review → Save

8. **Review & Publish**
   - Review all sections
   - Fix any warnings
   - Send for review
   - Wait for approval (2-7 days)
