## 📋 STEP-BY-STEP AD SETUP

### INSTAGRAM ADS (Meta Ads Manager)

1. **Go to:** https://business.facebook.com/adsmanager
2. **Create Campaign:**
   - Objective: App Installs
   - Campaign Name: "HeartLink - Dating App"

3. **Ad Set Settings:**
   - Location: India (Tier 1: Mumbai, Delhi, Bangalore, Pune, Hyderabad)
   - Age: 18-35
   - Gender: All (or split campaigns for M/F)
   - Interests: Dating, Relationships, Romance, Tinder, Bumble
   - Budget: ₹300/day for 5 days

4. **Ad Creative:**
   - Upload: instagram_ad_1.png or instagram_ad_2.png
   - Primary Text: "Find your perfect match with AI! 💕 100% verified profiles. Safe & secure dating."
   - Headline: "Download HeartLink Free"
   - CTA Button: "Install Now"
   - Link: https://play.google.com/store/apps/details?id=com.heartlink.app

### FACEBOOK ADS

1. **Same Ads Manager** as Instagram
2. **Ad Set Settings:**
   - Placement: Facebook News Feed, Marketplace
   - Age: 22-40 (slightly older for serious relationships)
   - Budget: ₹200/day for 4 days

3. **Ad Creative:**
   - Upload: facebook_ad.png
   - Primary Text: "AI-powered matchmaking finds you the perfect partner! 🎯 Verified profiles, safe dating. Join 50,000+ happy Indians."
   - Headline: "HeartLink - India's Safest Dating App"

### GOOGLE ADS

1. **Go to:** https://ads.google.com
2. **Create App Campaign:**
   - Campaign Type: App
   - App: HeartLink (search your app)
   
3. **Settings:**
   - Target: India
   - Budget: ₹100/day
   - Bidding: Target CPI (Cost Per Install) ₹15-20

4. **Ad Assets:**
   - Headlines (add 5):
     - "Find Love on HeartLink"
     - "AI Dating App - Free Download"
     - "India's Safest Dating App"
     - "Verified Profiles Only"
     - "Meet Your Perfect Match"
   - Descriptions (add 5):
     - "AI matchmaking + verified profiles"
     - "Safe dating for Indians"
     - "50,000+ happy users"
     - "Free to download & use"
     - "Women-first safety features"

## 📊 TRACKING & OPTIMIZATION

### Install Facebook Pixel
Add to website for conversion tracking:
- Go to Events Manager
- Create new Pixel
- Install on heartlink.co.in

### UTM Parameters
Use these links for tracking:
```
Instagram: https://heartlink.co.in?utm_source=instagram&utm_medium=paid&utm_campaign=app_install
Facebook: https://heartlink.co.in?utm_source=facebook&utm_medium=paid&utm_campaign=app_install
Google: Auto-tracked by Google Ads
```

### Key Metrics to Monitor
- Cost Per Install (CPI) - Target: ₹10-20
- Click-Through Rate (CTR) - Target: 1-2%
- Conversion Rate - Target: 10-15%

## 🎯 OPTIMIZATION TIPS

1. **Test Multiple Creatives** - Run 2-3 ad variations
2. **Target 18-28 Age** - Highest dating app users
3. **Focus on Tier 1 Cities** - Better conversion
4. **Run Ads 6PM-11PM** - Peak app usage time
5. **Retarget Website Visitors** - Higher conversion
